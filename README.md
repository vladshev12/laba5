# Лабораторная №5 Обход бинарного дерева
## Реализованные функции
1.  `preorder`-прямой обход
2. `incorder`-симметричный обход
3. `posrorder`-обратный обход
4. `level_order`-обход в ширину (BFS) по уровням
5. Вывод «левого вида» дерева (первый узел на каждом уровне)
